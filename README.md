# Adgrafer · Demostración de la plataforma

Sitio estático de un solo archivo, sin build.

## Publicar en Vercel
- Arrastre esta carpeta en vercel.com/new, o
- ejecute `npx vercel --prod` dentro de la carpeta.

Framework preset: **Other**. Sin build command ni output directory.

## Enlaces directos
Agregue un hash a la URL para abrir una pantalla: `#home`, `#wizard-result`, `#chat`, `#cart`, `#register`, `#checkout`, `#confirm`, `#p-home`, `#p-suggested`, `#p-benefits`, `#p-account`, `#int`.

Datos de ejemplo.
