# Portal Adgrafer · prototipo

Sitio estático, sin build.

- `/` → prototipo navegable (index.html)
- `/mockups` → pantallas de referencia (mockups.html)

## Publicar
- Arrastrar esta carpeta en vercel.com/new, o
- `npx vercel --prod` dentro de la carpeta.

Framework preset: **Other**. Sin build command ni output directory.
