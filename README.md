# Adgrafer · Demostración de la plataforma

Sitio estático de un solo archivo (`index.html`), sin build. Datos de ejemplo.

## Actualizar desde GitHub
1. Reemplace en el repositorio los archivos de esta carpeta (`index.html`, `vercel.json`, `README.md`).
2. Haga commit y push a la rama conectada en Vercel (normalmente `main`).
3. Vercel publica el cambio automáticamente en https://adgrafer.vercel.app/

Configuración del proyecto en Vercel: Framework preset **Other**, sin build command, output directory en la raíz.

## Enlaces directos
Agregue un hash a la URL para abrir una pantalla:
`#home`, `#wizard-result`, `#chat`, `#cart`, `#register`, `#checkout`, `#p-home`, `#p-suggested`, `#p-benefits`, `#int-resumen`, `#int-pagos`, `#int-ofertas`, `#int-beneficios`, `#int-envios`, `#int-mayorista`, `#int-asistente`, `#int-usuarios`.
